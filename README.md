# 📊 Mobile Sales Analytics Report  

## 📌 Overview  
This project analyzes mobile sales data to generate insights on sales performance, trends, and customer behavior.

## 🛠️ Tools Used  
- Excel  
- SQL  
- Power BI / Tableau  

## 📊 Key Insights  
- Top-selling brands and models  
- Sales trends over time  
- Region-wise performance  

## 📈 KPIs  
- MTD (Month-to-Date)  
- QTD (Quarter-to-Date)  
- YTD (Year-to-Date)  

## 🚀 Usage  
Open the dashboard file in Power BI / Tableau to explore insights.

## 💡 Future Scope  
- Sales forecasting  
- Real-time data integration
